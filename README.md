# Next.js 50 Code Challenges

50 structured challenges from Beginner → Intermediate → Advanced.

## Quick Start

```bash
npm install
npm run dev        # http://localhost:3000
```

## Scripts

| Command         | Description          |
|----------------|----------------------|
| `npm run dev`  | Start dev server     |
| `npm run build`| Production build     |
| `npm run lint` | ESLint check         |
| `npm test`     | Run unit tests       |
| `npm run test:e2e` | Run Playwright E2E |



## Challenge Map

| Range   | Level        | Topics                                        |
|---------|--------------|-----------------------------------------------|
| CH-01–18 | Beginner    | Routing, UI, components, metadata, deployment |
| CH-19–36 | Intermediate | Data, API routes, server actions, auth, SEO  |
| CH-37–50 | Advanced    | RBAC, streaming, testing, CI/CD, observability|
